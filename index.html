About the course

课程说明

这是一份可以长期生长的课程空间，而不只是一张课件下载清单。

学习目标

完成课程后，你将能够理解核心概念、熟练使用常见工具，并独立完成一个从需求分析到成果交付的实践项目。

学习方式

  • 课前阅读每讲的目标与准备材料。
  • 课堂中完成关键操作与小组讨论。
  • 课后通过实践任务巩固，并记录自己的工作方法。
课程内容只是起点。真正重要的是形成可以迁移到新问题中的思考框架。
模块一 · 建立认知

第1讲：课程导论与学习地图

本讲目标

第一讲不急着进入具体工具，而是先回答三个问题：我们为什么学习这门课、需要形成哪些能力，以及整个学期会怎样推进。

学习提示

记录一个你最希望在本学期解决的真实问题，它会成为后续实践项目的起点。

课程的三个层次

  1. 理解概念：建立共同语言。
  2. 掌握方法：选择合适工具并形成稳定流程。
  3. 完成项目：分析、设计、执行并复盘。
模块一 · 建立认知

第2讲：工具准备与高效工作流

推荐流程

明确目标 → 收集材料 → 建立目录 → 执行任务 → 质量检查 → 归档复盘

实践任务

为自己的课程项目建立目录，并用 README 写清楚项目目标、截止时间和交付标准。

模块二 · 核心方法

第3讲：信息检索与资料判断

检索不是一次输入

有效检索通常是循环过程：提出问题、查看结果、修正关键词、验证来源，再把新信息写回问题定义。
